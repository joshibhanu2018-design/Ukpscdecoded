# Decode Uttarakhand — Complete General Studies

**By UKPSC Decoded**

> For UKPSC (PCS/ACF/RFO), Lower PCS, RO/ARO, UKSSSC, Patwari, Lekhpal & All Uttarakhand State Examinations

## Book Structure

- **28 Chapters + Appendix**
- **Two Editions**: English & Hindi (separate books)
- **Coverage**: Prelims + Mains (Paper V & VI)

## Repository Structure

```
book/
├── english-edition/
│   ├── chapters/          # All 28 chapters (formatted, book-ready)
│   ├── appendix/          # Current Affairs Capsule, Data at a Glance
│   └── front-matter/      # Title page, Preface, TOC, How to Use
├── hindi-edition/
│   ├── chapters/
│   ├── appendix/
│   └── front-matter/
└── resources/
    ├── pyqs/              # Previous Year Questions (organized by chapter)
    ├── raw-content/       # Source material dumps
    └── images/            # Maps, diagrams, tables (if any)
```
