## 19.5 HUMAN-WILDLIFE CONFLICT (HWC) — DETAILED ANALYSIS

### Causes

| Factor | Details |
|---|---|
| **Habitat Fragmentation** | Linear infrastructure (highways, rail) cuts migration routes |
| **Prey Base Depletion** | High tiger density in Corbett pushes leopards to human fringes |
| **Invasive Species** | Lantana + Parthenium destroy understory → reduces herbivore fodder → predators enter villages |
| **Climate & Fires** | Dry spells + Pirul fuel → fires destroy habitat → wildlife moves to villages |
| **Corridor Breaking** | Kanha-Corbett corridor compromised |

### Multi-Dimensional Impact

| Impact | Details |
|---|---|
| **Palayan Trigger** | Crop depredation by monkeys/wild boar = primary reason for farm abandonment; >80% crop loss in Rudraprayag/Chamoli |
| **Feminization of Risk** | Women encounter predators during firewood/fodder collection |
| **Education Deficit** | Wildlife movement hampers school access in remote blocks |
| **Ghost Villages** | HWC drives abandonment of terraced farms |

### Conflict Species

| Species | Pattern |
|---|---|
| **Leopards (Guldar)** | Most frequent attackers in Almora, Pauri, Tehri; enter habitations |
| **Elephants** | Encroachment on Shivalik Elephant Reserve corridors |
| **Monkeys/Wild Boar** | Declared **"Vermin"** in high-conflict tehsils; main agricultural destroyers |

### Mitigation Strategies

| Strategy | Details |
|---|---|
| **Compensation** | Death compensation raised from ₹6 lakh → **₹10 lakh** |
| **Animal Rescue Centres** | Under CAMPA in Pauri and Chidiapur |
| **AI Railway Warnings** | For elephants at WII Dehradun |
| **Drone Surveillance** | Real-time tracking of wildlife movement |
| **Radio-Collaring** | "Problem" leopards tracked in real-time |
| **Bio-Fencing** | Agave + cactus barriers around farms |
| **Crop Diversification** | Aromatic/Medicinal Plants (Rose, Lavender) = safe from monkey attack (Mehak Kranti) |
| **Solar Fencing** | ₹20 crore allocation |
| **Pirul Removal** | Reduces fire → reduces animal displacement |
| **Mukhyamantri Ghasiyari Yojana** | Subsidized silage at village level → women don't need to enter forests |
| **SARA** | Restores forest water sources → wildlife doesn't enter villages for water |

## 19.9 TOURISM — ISSUES & CHALLENGES

| Issue | Details |
|---|---|
| **Carrying Capacity Breach** | 7 crore tourists vs 1 crore population; Mussoorie/Nainital exceeded structural limits; NGT-mandated audits |
| **Ecological Fragility** | Construction on paraglacial slopes (Joshimath crisis); concretization over Naulas |
| **Pollution & Waste** | High-altitude eutrophication (Hemkund, Roopkund); plastic on pilgrimage routes |
| **Seasonality** | Concentrated in summer/Char Dham months; job insecurity; resource hollowing |
| **Distance Penalty** | Remote areas (Pithoragarh, Munsiyari) still under-connected |
| **Hydrological Choking** | Hotel construction blocks spring recharge zones → summer water shortages |

| Policy/Initiative | Details |
|---|---|
| **Tourism Policy 2023** | USD 10 billion target by 2030; sustainable focus; 100+ PPP projects |
| **Char Dham Pariyojana** | 889 km all-weather road + Rishikesh-Karnaprayag rail (125 km) |
| **Homestay Scheme** | Up to 50% capital subsidy (₹15 lakh) + interest subvention for 5 years; 5,751 registered |
| **Manaskhand Mandir Mala** | 48 temples in Kumaon circuit → decongests Garhwal |
| **Spiritual-Economic Zones** | Budget 2026-27: Tehri + Champawat identified |
| **"Ghaam Tapo"** | PM initiative for winter tourism in sunny valleys |
| **Vibrant Villages** | Border tourism: Mana, Jadung, Gunji developed |
| **Category Subsidies** | Cat C (remote: Uttarkashi, Chamoli, Pithoragarh) = highest support |
| **Parvatmala Ropeways** | Kedarnath 12.9km, Hemkund 12.4km → reduces ecological footprint |
| **HEMS** | First state with Heli Emergency Medical Service (AIIMS Rishikesh) |
| **First Film Policy** | Updated 2024: 8× subsidies for Garhwali/Kumaoni/Jaunsari films |
| **Operation Kalanemi** | Removes fake sadhus from pilgrimage hubs |
| **Phone Ban in Dhams** | Sanctity maintenance |

## 19.11 WAY FORWARD — THE "SANTULAN" STRATEGY

| Strategy | Details |
|---|---|
| **Value over Volume** | Regenerative tourism that contributes to preservation |
| **Spatial Diversification** | Manaskhand (Kumaon) + Ghaam Tapo (winter) = spread across 13 districts, 12 months |
| **Eco-Friendly Transit** | Ropeways over road widening; electric heli-taxis for last mile |
| **Tech-Driven Management** | AI predictive analytics for crowd control + carrying-capacity audits |
| **Multi-Modal Hubs** | Rail/road to base camps → ropeways for eco-sensitive final miles |
| **Community-Led** | "Farm-to-Fork" experiences linking organic produce (House of Himalayas) with homestays |
| **GEP Integration** | Tourism revenue linked to ecological health metrics |
