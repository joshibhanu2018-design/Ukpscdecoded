## 12.3 THE REVENUE POLICE SYSTEM — A UNIQUE LEGACY

| Parameter | Details |
|---|---|
| **Established** | 1874 by Commissioner **Henry Ramsay** |
| **Originally Created** | 1819 by G.W. Traill (9 Patwari posts with dual powers) |
| **Coverage** | Operates in **~60% of the state's area** |
| **How It Works** | Revenue officials (Patwaris, Kanungos) exercise **police powers** of investigation and arrest |
| **Why Unique** | Low crime rate in hills made separate police uneconomical; combined revenue + policing in one official |
| **Current Status** | NOT fully removed; undergoing **phased transition** to Regular Police in crime-prone, tourist, and ecologically sensitive zones |
| **Criticism** | Lacks modern forensic training; inadequate for serious crimes |
| **No other Indian state** has this system at this scale |

## 12.5 OVERSIGHT AGENCIES — UKPSC, LOKAYUKTA & VIGILANCE

### A. Uttarakhand Public Service Commission (UKPSC)

| Parameter | Details |
|---|---|
| **Constitutional Basis** | Article 315 |
| **Established** | April 2001 |
| **Headquarters** | **Haridwar** |
| **First Chairman** | N.P. Navani |
| **Current Chairman (April 2024)** | **Ravi Dutta Godiyal** |
| **Primary Function** | Merit-based recruitment into state administrative and police services (UCS exam) |
| **Advisory Role** | Advises government on recruitment rules and disciplinary actions |
| **Recent Reform** | Backed by **Anti-Copying Law (2025)** — strictest in India (life imprisonment for paper leaks) |
| **Strategic Role** | Critical counter-force against youth out-migration (Palaayan) by ensuring transparent employment pathways |

### B. Uttarakhand Subordinate Service Selection Commission (UKSSSC)

| Parameter | Details |
|---|---|
| **Established** | September 17, 2014 |
| **First Chairman** | R.B.S. Rawat |
| **Current Chairman (April 2024)** | **Ganesh Singh Martolia** |
| **Function** | Conducts recruitment for Group C posts |

### C. Lokayukta (Anti-Corruption Ombudsman)

| Parameter | Details |
|---|---|
| **Legal Basis** | Uttarakhand Lokayukta Act, 2014 |
| **Jurisdiction** | Chief Minister, Ministers, Group A and B public servants |
| **First Lokayukta** | **S.H.A. Raja** |
| **Powers** | Civil Court powers — summon witnesses, mandate document production |
| **Challenge** | Prolonged vacancies and delays in appointments have historically weakened the institution |
| **Current Focus** | Strengthening autonomy and streamlining grievance mechanisms |

### D. State Vigilance Agency

| Parameter | Details |
|---|---|
| **Established** | 2002 |
| **Function** | Investigates corruption and abuse of office by state government officials |
| **Legal Framework** | Criminal Procedure Code, 1973 + Prevention of Corruption Act |
| **Police Stations** | Designated stations in **Dehradun** and **Haldwani** |
| **Key Tool** | **Anti-Corruption Helpline 1064** — citizens report bribery/graft directly via app |
| **Challenge (CAG finding)** | "Execution-Verification Collusion" — same officers execute and verify works, enabling fake claims |

## 12.6 SPECIALIZED ADMINISTRATIVE BODIES

### A. SETU Aayog (State Institute for Empowering & Transforming Uttarakhand)

| Parameter | Details |
|---|---|
| **Replaces** | Legacy State Planning Commission |
| **Modeled After** | NITI Aayog (national level) |
| **Core Philosophy** | Transition from tracking "Outlays" (money spent) to measuring "Outcomes" (actual public utility) |
| **Key Mandate** | Nodal agency for Sustainable Development Goals (SDGs); prepares State SDG Index |
| **Function** | Fosters cooperative sub-federalism; links block-level issues to state policy |
| **Current Focus** | Hill-specific solutions: carrying-capacity assessments, GEP (Gross Environment Product) |

### B. SARA (Spring & River Rejuvenation Authority)

| Parameter | Details |
|---|---|
| **Status** | Newly established authority |
| **Critical Mandate** | Map and revive "dying springs" (Dhara) across Tehri and Pauri belts |
| **Importance** | Mountain springs = primary water source for thousands of hill villages |
| **Integration** | Works with local governance; combines traditional water management with modern conservation |
| **Link to LSG** | Van Panchayats and PRIs implement SARA's revival plans on ground |

### C. UPNL (Uttarakhand Purva Sainik Kalyan Nigam Limited)

| Parameter | Details |
|---|---|
| **Established** | 2004 |
| **Function** | Premier agency for rehabilitation of veteran population |
| **Veteran Population** | ~1,38,372 ex-servicemen + 48,361 widows (March 2023) |
| **Primary Service** | Outsourced employment in government departments, medical colleges, corporations |
| **Challenges** | "Equal Pay for Equal Work" crisis; contractual job insecurity; skill mismatch (radar operators deployed as guards) |
| **Related Scheme** | **Him Prahari Yojana (2022)** — assistance for veterans to settle in border districts |
| **Eco-Task Forces** | Established 2008; employ ex-servicemen for afforestation and forest fire management |
| **Border Integration** | 355 farmers (including veterans) supplied 1.46 lakh kg meat/fish to ITBP = ₹6.58 crore via DBT |

### D. CPPGG (Centre for Public Policy and Good Governance)

| Parameter | Details |
|---|---|
| **Function** | State's internal think-tank for evidence-based policy formulation |
| **Key Activities** | Baseline surveys on carrying capacity (Nainital, Mussoorie); manages State Indicator Framework |
| **Link to SETU** | Provides technical support to SETU Aayog for monitoring schemes like Lakhpati Didi |
| **Achievement** | Helped Uttarakhand rank **1st in India for SDGs (2023-24)** |
| **Hill Spirit** | Ensures policies align with "spirits of the Hill State" — ecological development over blind infrastructure |

### E. Revenue Council

| Parameter | Details |
|---|---|
| **Function** | Apex body for land administration |
| **Location** | Dehradun |

### F. UCOST (Uttarakhand Council for Science & Technology)

| Parameter | Details |
|---|---|
| **Key Role** | Organizes World Summit on Disaster Management (WSDM) |
| **Science Leadership** | Coordinates research in disaster, climate, and biodiversity |

### G. Other Specialized Bodies

| Body | Details |
|---|---|
| **UREDA** (Uttarakhand Renewable Energy Development Agency) | HQ: Almora |
| **Uttarakhand Biotechnology Council** | Established in Pantnagar |
| **Badrinath-Kedarnath Temple Committee (BKTC)** | Statutory custodian managing pilgrim logistics, finances, sanctity of two Dhams (6 crore+ annual visitors) |

## 12.8 THE PEVD PARADOX — CRITICAL ANALYSIS OF ADMINISTRATION

> *CAG-identified systemic failures in state administration*

| Element | Failure | Example |
|---|---|---|
| **P** (Planning) | Projects approved without ground surveys | ₹10.79 crore wasted in Kedarnath — lack of land sanction |
| **E** (Execution) | Poor contractor oversight; incomplete work | Dehradun Smart City: ₹76 crore paid, ₹19 crore unrecovered |
| **V** (Verification) | Same officer executes AND verifies (collusion) | ₹3.79 crore detected in fake skill development claims |
| **D** (Delivery) | Assets built but non-functional | STPs (Namami Gange) built but water quality unchanged |

### Additional Administrative Challenges

| Challenge | Details |
|---|---|
| **Fiscal Strain** | ~60% revenue consumed by committed expenditure (salaries, pensions, interest) |
| **Hill-Plain Norm Disconnect** | "One-size-fits-all" norms from plains fail in low-density, high-altitude regions |
| **Staff Shortages** | Chronic shortage of technical staff (being addressed in 2025-26 recruitment) |
| **Budget Surrender** | ₹2,366 crore returned unspent (DPRs without ground reality) |

### Way Forward (Administrative Reforms)

| Reform | Details |
|---|---|
| **Hill-Specific Norms** | Define service delivery based on distance/terrain, NOT population alone |
| **Decouple Audit from Execution** | Mandatory independent third-party audits for major projects |
| **Geo-tagging + AI** | Mandatory before clearing contractor bills |
| **Outcome-Based Budgeting** | SETU Aayog model — track results, not expenditure |
| **Cyber Resilience** | ₹15 crore IT security budget; scale up CERT-UTK |
| **CAG Compliance Cell** | In CMO — audit findings trigger immediate FIRs, not just departmental inquiries |
