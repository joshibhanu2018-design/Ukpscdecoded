# UKPSC Decoded — PYQ Trackers & Prep Schedule

## 📁 Files in this repository

| File | What it is | Covers |
|------|-----------|--------|
| `UKPSC_PYQ_Tracker_UTTARAKHAND.csv` | Uttarakhand-specific PYQ repeat-topic tracker | ~35% of paper — 10 clusters |
| `UKPSC_PYQ_Tracker_NATIONAL.csv` | National/General topics PYQ tracker | ~65% of paper — 14 clusters (A-N) |
| `UKPSC_60_Day_Prep_Tracker.csv` | Day-by-day 60-day prep schedule | All 60 days mapped to clusters |

## 📊 How to use

1. Download the CSV files
2. Open in Apple Numbers / Google Sheets / Excel
3. Use the STATUS column to track your progress (✓ / ✗)
4. Follow priority levels: ⚡ CRITICAL → 🔴 HIGH → 🟡 MEDIUM
