# Script Writing Rules for UKPCS Decoded YouTube Channel

## When to Apply
Apply these rules whenever the user asks to write a script, create a hook, draft video content, or anything related to YouTube video creation for the UKPCS Decoded channel.

## Reference Document
The complete scriptwriting framework is defined in: #[[file:MASTER_SCRIPT_WRITING_PROMPT.md]]

## Core Instructions

When the user says something like:
- "Write a script on [topic]"
- "Create a hook for [topic]"
- "Script likh do [topic] pe"
- "Video script banao"
- Any variation asking for video/script content

**Follow the MASTER_SCRIPT_WRITING_PROMPT.md document COMPLETELY.** Specifically:

### Mandatory Steps:
1. **First write 5-7 bullet points** (internal value check — if bullets are weak, suggest improvements before writing full script)
2. **Write the HOOK first** (0-30 seconds) using Pattern Interrupt + Personal Stakes + Curiosity Gap
3. **Then write the BODY** using But-Therefore format, Emotional Cycles, Dopamine Loops
4. **Include formatting marks:** [PAUSE], [VISUAL: description], [TONE: cue], [LOOP], [PATTERN BREAK]
5. **End with an open loop** — never a traditional "like share subscribe" ending
6. **Run through the Quality Checklist** and report which items pass/fail

### Target Audience (Always Remember):
- Uttarakhand PCS (UKPSC) aspirants, age 25-35
- Hindi conversational tone, "तुम" not "आप"
- Pahadi cultural context (Garhwali/Kumaoni references where natural)
- Pain points: coaching limitations, family pressure, failed attempts, peer comparison
- Aspirations: SDM/BDO/Naib Tehsildar, financial stability, family pride

### Style:
- Short punchy sentences
- Rhetorical questions every 30-45 seconds
- Uttarakhand-specific examples (districts, local governance, pahadi life)
- Level 4-6 storytelling (empathy + word craft + cultural nuance)
- Imagine speaking to a 27-year-old in a Dehradun library on his 2nd/3rd attempt

### What the User Will Provide:
- Topic (mandatory)
- Video length (optional — default 10 minutes)
- Key points to cover (optional — if not given, research and suggest)
- Any special instructions

### Output Format:
```
## BULLET POINTS (Internal)
- point 1
- point 2
...

## HOOK (0-30 sec)
[Full scripted hook with marks]

## CONTEXT (30 sec - 1:30 min)
[CVF section]

## BODY
[Main content with all formatting marks, loops, transitions]

## ENDING (Open Loop)
[Final section]

## QUALITY CHECKLIST
- [x] or [ ] for each of the 12 items
```
